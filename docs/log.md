# Bundle Update Log

## 2026-07-04

* **Update**: Reader/chat UX pass. (1) `PaperCard` now previews `Paper.ai_summary` (already returned by the backend `Paper` schema) instead of raw `content_text` scraped by pymupdf; renders nothing until a summary exists. (2) Zen/fullscreen reading (`ReaderShell`'s `zen` state) now also collapses the PDF viewer's thumbnail/outline sidebar and suppresses the annotation margin-card layout via new `PDFViewerHandle.setThumbnailSidebarOpen`/`getThumbnailSidebarOpen` methods, so the page recenters using the existing `flex justify-center` page layout — restored on exit. (3) The right-side panel tab (Details/Insights/Chat/...) is now stored per paper tab as `Tab.panelTab` in [state-management](/frontend/state-management.md)'s `TabContext`, so switching between open paper tabs no longer resets it to "Details"; `Layout.tsx` derives `activeTab` from the active tab instead of local state. (4) Replaced several full-page/panel loading spinners with `Skeleton`-based placeholders (`PaperDetail`, `ReaderShell`'s PDF-load state, `RelatedPapers`, `DiscoveryArchive`, and the initial-fetch states of `AISummary`/`KeyFindings`/`ReadingGuide`) — inline button-pending spinners (regenerate/export/etc.) were left as-is. (5) Restyled the chat tool-call list and reasoning panel (`ToolCallIndicator`, `AgentThoughtPanel`) into a single bordered/muted card with status icons instead of a bare list of colored dots. (6) Fixed a post-stream chat flicker: `useChatController`'s delayed cache invalidation after a turn completes now uses `refetchType: 'none'` on the visible session query — see [chat-system](/frontend/chat-system.md) — so it no longer force-refetches and swaps optimistic (temp-id) messages for server ones (which was remounting the message list) right after streaming finishes.

## 2026-07-03

* **Reformation batch 5 (frontend UX)**: (1) Softer 401 handling — `fetchApi` now classifies refresh failures as `auth_failed` (401/403 → session teardown) vs `transient` (network/5xx → 1s backoff + one retry, session preserved); concurrent 401s share one refresh promise; `AuthContext.scheduleRefresh` retries transient failures 3× with backoff before `clearAuth()`. (2) Chat rate-limit retry UX — `useChatStream` auto-retries `rate_limit` errors (2 attempts, 5s/15s backoff), exposes `autoRetryAt`; `ErrorBanner` shows a live countdown; controller toasts "retrying in Ns" instead of an error. (3) Semantic-search-unavailable signal — `EmbeddingService.is_available()`, `GET /search/capabilities`, `semantic_available` on `SearchResponse` (POST `/search` short-circuits to empty results when no embedding key), amber notice + "Use full-text" fallback on the Search page. (4) Server-side recents — `user_paper_state.last_opened_at` (migration `add_last_opened_at`), touched in `increment_view_count`; `GET /papers/recent`; Dashboard prefers "Recently Opened" over "Recently Added" once present. Affected [api-layer](/frontend/api-layer.md), [chat-system](/frontend/chat-system.md), [infra](/backend/api/infra.md), [papers](/backend/api/papers.md), [database](/backend/database.md). Batch 4 (route/DB integration tests) skipped per owner decision — no testing setup wanted for now.
